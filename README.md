Aplicación analítica desarrollada durante el bootamp de análisis de datos de Jupi Digital. A partir de la base de datos de Contoso, a la cual se conecta desde Google Big Query (al tener licencia de Qlik Sense Cloud durante el bootcamp, una vez finalizado no se cuenta más con la conexión. Por lo tanto, no es posible volver a cargar los datos).
A través de la metodología de implementación por capas, se desarrolló una aplicación para cada una de ellas. En la extracción se procuró conservar los datos crudos, como vienen del origen y almacenarlos en QVD. Luego, estos QVD son leídos en la segunda capa de transformación, donde se realizan las transformaciones necesarias. Estas se realizan con el propósito de poder construir, en la tercera capa, un modelo estrella. Para ello, se construyeron las tablas maestras para cada dimensión y una única tabla de transacciones con la que se relacionan cada una de las tablas dimensionales.

Tanto los .qvf de extracción como de transformación se disponibilizan. Sin embargo, por lo comentado anteriormente, al no contar con la conexión a la base de datos original no se pueden realizar los proceso de carga. Mientras que, el .qvf con el modelo y las visualizaciones es demasiado pesado, por lo que, solo se incluyen las transformaciones realizadas. Para el tablero construido puede recurrirse a las capturas almacenadas (dashboard).
